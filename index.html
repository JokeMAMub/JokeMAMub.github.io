Personal Drive Sync

Personal Drive Sync is a private, single-user workflow on Windows that uses rclone to transfer files from the owner's computer to the owner's Google Drive. It can be triggered when the owner's Deluge downloads are complete.

What the application does

  • Uses the owner's Google authorization to access the owner's Google Drive.
  • Uploads selected local files and folders to the owner's Google Drive.
  • Checks transfer completion before local cleanup, as configured by the owner.
  • Runs locally on the owner's Windows computer; this website is informational only.

Who can use it?

This application is for the owner's personal use and is not offered as a public service. The website does not request a Google sign-in, account credentials, or file uploads.

This is an independently configured personal workflow and is not affiliated with Google, GitHub, or rclone.
